# ANVESHAN - अन्वेषण

A sovereign, offline-first research search engine for Indian public knowledge.

- **Retrieval**: BM25 (k1 1.45, b 0.72) over boosted title/tag fields, blended with a TF-IDF cosine pass. Written from scratch, no dependencies.
- **Language**: script-aware tokeniser, roman-to-Devanagari transliteration, Indic domain thesaurus (Devanagari and Hinglish queries hit English sources).
- **Answer layer**: extractive sentence selection with MMR de-duplication; every sentence is quoted from an indexed document and carries a citation.
- **Provenance**: SHA-256 Merkle tree over all documents plus a hash-linked query chain, computed with the Web Crypto API on the reader's device.
- **Agent**: Pragya, an on-device chat agent with intent routing and follow-ups. Optional adapter to Sarvam-105B chat completions if you supply your own key.
- **Index**: 50 documents from PIB, MeitY, UIDAI, NPCI, AI4Bharat, C-DAC, ISRO, RBI and Sarvam AI documentation.

## Honest scope

This is a working search engine over 50 curated Indian source documents, not a crawler over the Indian web.
It does not index live pages, it does not call Bhashini or Sarvam unless you add a key, and the Merkle ledger
is local - it is not a live Vishvasya network node. The retrieval maths, the ranking, the language handling,
the cryptographic verification and the citation discipline are real; everything else is labelled as what it is.

## Run it

Open `index.html` in any modern browser. No server, no build step, no network.
